Política de privacidad de sasu-schedule

Última actualización: 3 de octubre de 2026

sasu-schedule es una aplicación personal de control horario, de uso privado, que se ejecuta en el servidor del propio titular. Esta política explica qué datos trata y con qué finalidad.

1. Datos que trata la aplicación

  • Registros de fichaje (horas de entrada y salida, pausas, notas del día y reglas de horario). Se guardan en una base de datos PostgreSQL alojada en el servidor del propio titular. No se envían a terceros.
  • Credenciales de acceso: una passkey (huella o PIN) y, para el primer acceso, la cuenta de Google del titular.

2. Datos de las API de Google

La aplicación usa las API de Google únicamente de dos formas:

  • Inicio de sesión con la cuenta de Google del titular, para identificarlo. Solo se conserva su dirección de correo electrónico.
  • Copia de seguridad en Google Drive, con el permiso https://www.googleapis.com/auth/drive.file. Este permiso da acceso únicamente a los ficheros que la propia aplicación crea; no permite ver ni modificar el resto del Drive del usuario. La copia se cifra en el servidor con AES-256-GCM antes de subirse, de modo que Google almacena un fichero cifrado que no puede leer.

Los datos obtenidos de las API de Google no se comparten con terceros, no se usan para publicidad, no se venden y no se emplean para entrenar modelos. El titular puede revocar el acceso en cualquier momento desde myaccount.google.com/permissions.

sasu-schedule's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

3. Conservación y eliminación

Los datos permanecen en el servidor del titular hasta que este los borra. Las copias de seguridad en Google Drive se conservan según su propia retención (14 copias por defecto) y pueden eliminarse en cualquier momento borrando la carpeta de copias y revocando el acceso de la aplicación.

4. Terceros

No se comparte información con terceros. La aplicación solo se comunica con los servicios de Google necesarios para el inicio de sesión y la copia de seguridad.
